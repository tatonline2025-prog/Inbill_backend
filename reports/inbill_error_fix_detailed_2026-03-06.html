Danh Sách Lỗi & Cách Fix

# Mức độ Lỗi Vị trí Cách fix đã áp dụng Trạng thái
1 Critical Privilege escalation: sửa thông tin user không bắt buộc admin src/routes/userRoute.ts, src/controllers/userController.ts Thêm authorize(["admin"]) ở route và check role trong controller. Fixed
2 Critical Privilege escalation: update fee user không bắt buộc admin src/routes/userRoute.ts, src/controllers/userController.ts Thêm guard admin ở route và controller. Fixed
3 High Data exposure: fetch toàn bộ user không auth src/routes/userRoute.ts Đổi route thành authenticate + authorize(["admin"]). Fixed
4 High Public write endpoint: quick-add invoice src/routes/invoiceRoutes.ts Yêu cầu authenticate cho /quick-add. Fixed
5 High Public export endpoint (invoice exports) src/routes/invoiceRoutes.ts Khóa quyền admin cho /exportExcelPrinted, /exportExcelByUser, /exportExcelCollected, và endpoint for-copy. Fixed
6 High Admin export transaction thiếu authorize admin src/routes/transactionRoutes.ts, src/controllers/transactionController.ts Thêm authorize(["admin"]) ở route + check role trong controller (defense-in-depth). Fixed
7 High Endpoint compute nặng mở public (/optimal-sum) src/routes/sumRoute.ts Khóa endpoint bằng authenticate + authorize(["admin"]). Fixed
8 Medium Request có thể treo khi save layout với layoutID không tồn tại src/controllers/invoiceLayoutController.ts Nếu không tìm thấy bản ghi cũ thì tạo mới và luôn trả response. Fixed
9 Medium Error leakage (trả raw error/detail ra client) src/controllers/invoiceLayoutController.ts, src/controllers/invoice.excel.controller.ts Loại bỏ trả object lỗi thô, chỉ trả message an toàn. Fixed
10 Medium Startup flow rủi ro: listen trước khi DB ready + drop index lặp src/server.ts, src/models/invoiceModel.ts Refactor startup theo thứ tự: connect DB -> drop index 1 lần -> listen; bỏ IIFE drop-index ở model. Fixed
11 Medium Unsafe env usage (process.env.X!) src/config/db.ts, src/middleware/auth.ts, src/controllers/authController.ts Thêm src/config/env.ts để validate env bắt buộc và dùng helper thay non-null assertion. Fixed
12 Low Thông báo lỗi placeholder "..." src/controllers/transactionController.ts Đổi thành thông báo phân quyền rõ ràng + mã HTTP 403 phù hợp. Fixed
13 Medium Pipeline test fail giả do script placeholder package.json Thêm script typecheck và set test = npm run typecheck. Fixed
14 High Vulnerability dependency xlsx package.json, src/controllers/invoice.excel.controller.ts, createTestExcel.js Migrate import/export Excel sang exceljs và gỡ hoàn toàn xlsx. Fixed
